# Sensoriis ARC Firmware Releases

This repository contains official firmware releases for the **Sensoriis ARC** precision landing and tethering system.

> ⚠️ **Do not clone or use files from this repository directly.** All firmware should be flashed using the Sensoriis Tools portal.

---

## Flashing Firmware

To update your Sensoriis ARC firmware, visit the tools portal:

**[tools.cambsensoriis.com](https://tools.cambsensoriis.com)**

The portal provides a browser-based firmware uploader along with any additional tools required for setup and configuration of your device.

---

## Documentation

Full documentation for the Sensoriis ARC precision landing and tethering system is available at:

**[docs.cambsensoriis.com](https://docs.cambsensoriis.com)**

This includes integration guides, configuration references, and troubleshooting.

---

## Releases

Firmware releases are published under the [Releases](../../releases) tab of this repository. Each release includes:

- Flashable firmware binary (`.bin`)
- Release notes detailing changes, fixes, and known issues
- SHA256 checksum for verification

It is recommended to always use the latest stable release unless instructed otherwise by Sensoriis support.
